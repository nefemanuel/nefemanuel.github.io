# nefemanuel.github.io

Source for the academic website of Neftalem Emanuel: <https://nefemanuel.github.io>

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (MIT licence) and deployed by the GitHub Actions workflow in `.github/workflows/jekyll.yml`.

## Where things live

- `_pages/` – About, Research, Software and CV pages
- `_publications/` – one file per publication
- `files/cv.pdf` – the CV shown on the CV page
- `images/profile.jpg` – profile photo
- `_config.yml` and `_data/navigation.yml` – site settings and menu
